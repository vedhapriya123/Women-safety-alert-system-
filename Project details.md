Women Safety Alert System

Project Title

Women Safety Alert System Using GPS and Emergency Alert Technology

---

Problem Statement

Women often face unsafe situations while traveling or staying alone, and it may be difficult to quickly contact family members or emergency services. Existing safety measures may not provide instant location tracking or rapid communication during emergencies. Therefore, there is a need for a smart and reliable system that can send emergency alerts with the user's live location to trusted contacts, improving personal safety and enabling faster assistance.

---

Project Objectives

- To provide a quick and easy way for women to send an emergency SOS alert.
- To share the user's current GPS location with registered emergency contacts.
- To enable real-time tracking during emergency situations.
- To reduce the response time of family members or authorities.
- To create a simple, user-friendly, and secure safety application.

Project Description

The Women Safety Alert System is a smart safety application developed to help women during emergency situations. By pressing an SOS button, the application automatically sends an alert message along with the user's live GPS location to registered emergency contacts. The system aims to provide immediate assistance and improve personal security using modern technologies such as GPS tracking, mobile notifications, and real-time communication.
